## ✨ Key Features

- 💎 **Glassmorphic UI**: Translucent player card with real-time backdrop blur effects and smooth hover states.
- 💿 **Interactive Vinyl Record Animation**: Realistic vinyl record that slides out from behind the album art cover and spins during playback.
- 🌈 **Ambient Background Glow**: Floating, multi-colored background blobs that create a modern studio ambiance.
- 🔍 **Live Search Filter**: Filter through your playlist instantly by song title or artist name.
- ⚡ **Enhanced Audio Controls**:
  - Variable Playback Speed Switcher (`0.5x`, `1x`, `1.25x`, `1.5x`, `2x`).
  - Repeat Single / Repeat All & Shuffle modes.
  - Interactive scrub bar and volume slider with mute toggle.
- ⌨️ **Built-in Keyboard Shortcuts**: Complete hands-free playback navigation.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| <kbd>Space</kbd> | Play / Pause playback |
| <kbd>←</kbd> | Seek backward (5 seconds) |
| <kbd>→</kbd> | Seek forward (5 seconds) |
| <kbd>↑</kbd> | Increase volume (+10%) |
| <kbd>↓</kbd> | Decrease volume (-10%) |

## 🛠️ Built With

* **HTML5** - Semantic markup structure and native `<audio>` element integration.
* **CSS3** - Custom Flexbox, CSS Keyframe Animations, Glassmorphism, and CSS Variables.
* **JavaScript (Vanilla ES6+)** - Dynamic DOM manipulation, audio event listeners, and keyboard handlers.
* **FontAwesome 6** - Vector control icons.
